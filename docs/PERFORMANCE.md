# 本地性能对比

2026-10-28，改造前提交 c94b824。macOS、10 逻辑核心、24 GiB 内存、Java 17.0.21，隔离 H2（MySQL 模式），MockMvc 含 HTTP 序列化、不含真实网络延迟。数据为合成的 10000 个项目、120000 条月收入和 100000 条进展，不使用用户数据。用户确认暂无独立测试环境，仅在本地使用。

| 操作 | 改造前耗时 | 数据库语句 | HTTP 请求数 |
| --- | ---: | ---: | ---: |
| 列表，30 个分页请求 | 454.20 ms，P95 25.28 ms | 90 | 30 |
| 1000 行预检 | 1439.58 ms | 6000 | 1 |
| 1000 行正式导入 | 1818.26 ms | 20000 | 1 |
| 10000 项目综合导出 | 618.28 ms | 5 | 1 |
| 1000 项目软删除 | 387.16 ms | 3000 | 1000 |

以上仅为本机前后对比基线，不是 4 vCPU／8 GB MySQL 验收；请求数和查询数是实际计量值，不能据此推断正式网络环境性能。测试使用 Hibernate prepareStatementCount 统计 ORM 语句，夹具的 JDBC 批量初始化不计入操作耗时。导入为更新现有项目，只有标准字段变更、不含新增产品或方案；应另测更复杂行的开销。

## 改造后本机实测

同条件合成数据，改造后启用持久任务的结果如下（毫秒，单次大样本，不是多轮 P95）：

| 操作 | 总执行时间 | 受理时间 | 数据库语句 | 提交请求数 |
| --- | ---: | ---: | ---: | ---: |
| 1000 行预检任务 | 2538.54 | 20.33 | 11153 | 1 |
| 1000 行正式导入任务 | 2364.03 | 9.94 | 14150 | 1 |
| 10000 项目综合导出任务 | 584.24 | 5.35 | 853 | 1 |
| 1000 项目批量软删除 | 119.30 | 4.23 | 6062 | 1 |

各任务均核对 SUCCEEDED、处理总数及失败数0，成功项没有跳过来制造耗时。查询数包含逐项事务、持久结果、进度及硬删除保护检查；后台任务不是“一条 SQL”，不能宣称所有操作的查询数都下降。轮询请求另计：基准每10ms查询状态，本机计入上述数据库语句；实际页面500ms等待、任务中心1秒轮询。

列表30个分页请求合计445.51ms，P95 **26.82ms**，150条数据库语句。新方案/责任关联带来额外读取。原同步接口保留兼容，实测预检3297.05ms（11000条）、写入2981.96ms（16000条）、综合导出6771.50ms（20条）、逐项软删除362.66ms（3000条/1000次请求）。同步大范围综合导出因更多关联及大 IN 范围读取比旧版慢，不能以旧接口结果声称全面加速；新界面使用100项目分块后台任务。

所有受理均小于1秒；本机1000写入、1000软删除、10000综合后端生成分别低于30/10/30秒目标，但硬件及数据库不符，**不算正式指标通过**。未采集真实MySQL慢查询日志/网络P95，也未正式验证10000行Excel生成期间的交互延迟。

浏览器已验证隔离新演示的25项目/54列综合导出，实际下载82,944字节，25行完整，预算为数值单元格，多方案JSON保留。刷新后任务进度/结果仍可查询。Worker代码及两种构建通过；本次浏览器文件上传受扩展未开放本地文件权限限制，解析/映射改由真实交付模板自动测试验证。浏览器大文件解析、列表刷新及文件生成的独立耗时尚未取得，不用后端耗时替代这些阶段。导入页已留 `excel-parse`、生成已留 `excel-generation` performance measure，具备浏览器权限后可通过开发者工具复测。

复测命令（backend）：

```bash
mvn -Dtest=PerformanceBaselineTest -Dbenchmark=true -Dbenchmark.async=true -Dbenchmark.label=after -Dbenchmark.output=/tmp/presales-baseline-after.json test
```

普通测试跳过大样本。正式MySQL迁移由隔离CI测试，性能与SQL恢复演练仍待环境，不能把迁移通过等同性能通过。
