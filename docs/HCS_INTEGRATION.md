## 已有基础

- 独立唯一的 `hcsOpportunityId`；通用 `externalId` 不猜测转换。
- `hcsStatus`、`lastSyncAt` 独立保存展示；本地状态不被覆盖。外部状态只读，普通项目写接口不接受覆盖。
- 人员库、别名、多命中、来源分离。只有完整且无歧义的 HCS 人员列表才替换 HCS 来源；失败/不完整/歧义保留旧关联，不影响手工来源。
- 持久任务、逐项事务、重试和进展去重可供未来适配层复用。人员领域合成测试不等同 HCS 端到端同步。

## 必须取得的资料

API 地址/版本、鉴权/令牌生命周期/权限、脱敏请求响应、状态代码表、进展稳定标识/业务时间、人员工号/账号字段、分页/限流/失败语义、增量能力。不能预设有增量或稳定进展 ID。

取得后制作真实字段对照并实现独立适配层。不把不确定字段写进固定映射。未绑定记录进入待关联清单，不按名称自动覆盖或创建。
