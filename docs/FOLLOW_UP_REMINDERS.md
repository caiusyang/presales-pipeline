# 固定靶跟进提醒

日期：2026-10-29。基线 `dfe31c5`。只使用当前工作树、合成测试数据和隔离演示来源，不重置既有浏览器数据，不对用户正式库执行迁移。

## 确认口径

- `fixedTarget`（是否固定靶）决定周期，默认“是”7 天、“否”14 天。
- `projectLevel`（项目级别）为无风险、低风险、高风险，可留空。风险级别不决定周期，不等同于重点/一般项目。
- 只提醒未删除、本地售前状态非中标的活动项目。HCS 独立状态不参与此判断。
- 按上海自然日，到第 7/14 天开始提醒，之后显示逾期天数。例如 10 月 22 日跟进的固定靶项目，10 月 29 日“今天需跟进”，10 月 30 日“逾期 1 天”。
- 基准为只读 `lastFollowUpAt`，没有时回退到创建时间；不使用升级当天。真实项目/方案/产品/责任人/进展/收入变化刷新基准，查看、导出、无变化保存不刷新。
- 原下次行动日期提醒保持独立，不因这次提醒自动清空。

## 使用

新建、详情编辑和列表双击均可修改是否固定靶和项目级别。列表新增跟进提醒列，可在列配置中控制显示；保留原有列偏好，新列追加，不覆盖已保存配置。

“只看需跟进”统计当前其他筛选条件下全部分页，筛选在数据库分页前执行。是否固定靶、项目级别可独立组合筛选；改变条件清空旧的批量勾选范围。跨日或页面重新获得焦点刷新提醒。原行动优先排序及用户手工排序不变。

“配置 → 跟进提醒”可修改两类周期，1—3650 天整数，保存到数据库/演示存储；不改写任何项目跟进时间。规则读取失败会明确显示，不能默用默认值掩盖错误。

## 导入、导出与历史数据

- 自动识别“是否固定靶”“固定靶”“固定靶项目”等表头，以及“项目级别”“风险级别”“风险等级”。可手工映射；不需要额外创建自定义字段。
- 是否固定靶明确识别是/否、true/false、1/0、yes/no、y/n，不按非空即是判断。无法识别的值进入待修正，可通过既有标准值对照或单行修正解决。
- 级别只接受三个确认值；不把“重点项目”等原值自动猜为某种风险。没有导入对应列时保留已有值；新项目默认非固定靶、未评级；显式清空级别恢复未评级。
- 原模板继续有效，按需增加两列表头。项目主表和综合导出的可选列包含两字段，固定靶导出为是/否；提醒本身是动态计算列，不导出为永久业务字段。
- V15 只新增列和规则表，不改历史迁移、不刷新跟进时间。历史未标记项目为非固定靶、级别为空，不能误标为无风险。
- JSON 备份含 `follow_up_policies` 及项目新字段，SQL 全量备份自然覆盖。只读恢复预检校验周期与枚举；旧 JSON 缺规则时明确警告需补默认规则，不擅自执行恢复或重置跟进时间。
- 新演示样本覆盖未到期/周期当天/逾期及三种风险，已有演示数据仅补缺失字段，不重新播种。
